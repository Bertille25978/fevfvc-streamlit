# Application Streamlit de prédiction du rapport FEV/FVC

Cette application permet de prédire le rapport FEV/FVC chez les sujets de sexe féminin à partir de l’âge et de la taille.

Le modèle utilisé est un Gradient Boosting Regressor.  
L’application fournit une prédiction moyenne ainsi que des limites inférieure et supérieure correspondant à un intervalle prédictif à 90 %.
